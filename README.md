# Conservation of Momentum – Christmas Edition

A GCSE Physics simulation of momentum and its conservation, with a Christmas theme.

- **Explore the sims:** Present toss, Reindeer kick and Sledge pile-up, with sliders, a values table and momentum arrows.
- **Calculation questions:** ten questions in five a/b pairs, with typed answers, a working-out pad, unit keys, hints, "Help me get started" and full screen.

Everything is in `index.html` (no build step). Pushing to `main` deploys it to GitHub Pages via `.github/workflows/deploy.yml`.

The working-out pad, feedback, saving and answer sheet are modelled on [awm11/ultrasound](https://github.com/awm11/ultrasound).

To let students move between questions only after answering correctly, set `FREE_NAV` to `false` in `index.html`.
